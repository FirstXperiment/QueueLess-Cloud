# QueueLess Cloud Development Planning

This section contains the implementation planning for QueueLess Cloud.

The root project README describes what QueueLess Cloud is. This README and the documents in this directory describe how the application will be built, in which order features will be delivered, and how the plan can evolve.

## Planning Documents

- [Development Roadmap](roadmap.md) — phased feature roadmap from project foundation to production release.

## Planning Principles

- Build functionality in complete, testable feature slices.
- Establish authentication and tenant isolation before exposing business data.
- Deliver the minimum viable scheduling workflow before advanced distributed-system features.
- Keep service-specific implementation details in the relevant service documentation.
- Update this planning section when priorities or approved requirements change.
